ОБНОВЛЕНИЕ САЙТА NIK PETROV PORTFOLIO

В архиве находятся файлы для обновления существующего сайта:
- index.html
- style.css
- script.js
- resume_nikita_petrov_RU.pdf
- resume_nikita_petrov_EN.pdf

КАК УСТАНОВИТЬ
1. Распакуйте архив.
2. Откройте свою существующую папку nik_petrov_portfolio.
3. Скопируйте пять файлов из архива в корень этой папки.
4. Подтвердите замену index.html, style.css и script.js.
5. НЕ удаляйте и не заменяйте папки images, а также images.json — в них находятся ваши портрет и скриншоты проектов.
6. Проверьте сайт локально, затем загрузите изменённые файлы и два PDF в корень GitHub-репозитория.

ЧТО ИЗМЕНЕНО
- Ссылка CONTACT в блоке резюме заменена на две прямые ссылки для скачивания PDF (RU и EN).
- Добавлены стили, чтобы обе ссылки аккуратно располагались на мобильных экранах.
- Исправлена подстановка путей изображений: скрипт использует полные относительные пути из images.json без повторного добавления папки images.

ПРОВЕРКА
- PDF-файлы должны лежать в корне сайта рядом с index.html.
- Пути в images.json должны быть относительными от корня сайта, например:
  images/trading-bot/имя-файла.png
- Проверка CSS на реальных устройствах и браузерный визуальный просмотр не выполнялись автоматически; после установки откройте сайт на ширинах 360, 390, 430, 768 и 1024 px.
