# Nik Petrov — Portfolio

Статический сайт-портфолио на HTML, CSS и JavaScript. Не требует сборки и подходит для GitHub Pages.

## Как открыть
Откройте `index.html` в браузере. Для проверки загрузки изображений и `images.json` удобнее использовать локальный сервер или сразу GitHub Pages.

## Как добавить скриншоты в карусель
1. Скопируйте изображения в папку нужного проекта:
   - `images/trading-bot/`
   - `images/cr13-analyst/`
   - `images/nanny-app/`
2. Откройте `images.json`.
3. Добавьте имена файлов в соответствующий список. Например:

```json
{
  "trading": ["01-main-screen.jpg", "02-signal.png"],
  "analyst": [],
  "nanny": []
}
```

4. Сохраните `images.json` и загрузите изменения в GitHub.

Поддерживаются JPG, JPEG, PNG и WebP. Имена и расширения должны точно совпадать. Чтобы убрать кадр, удалите его имя из списка. Порядок файлов в списке — порядок кадров в карусели.

## Как заменить портрет
Замените `images/portrait.png` своим подготовленным файлом, сохранив это имя. Рекомендуется PNG с прозрачным фоном. Если используете другое имя или формат — измените путь в `index.html`.

## Контакты
Проверьте Telegram и GitHub ссылки в `index.html` перед публикацией.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий GitHub.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, затем `main` и `/ (root)`.
5. Сохраните. Через некоторое время GitHub покажет адрес опубликованного сайта.
