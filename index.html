Автоматизация анализа криптовалютного рынка с помощью n8n и AI. Система отбирала ликвидные инструменты на нескольких биржах и отправляла торговые сигналы в Telegram.

ЗАДАЧА

Сократить время, которое трейдер тратит на ручной просмотр рынка, и автоматизировать первичный анализ большого количества торговых инструментов.

РЕШЕНИЕ

Workflow в n8n запускался по расписанию, получал данные через API Binance, MEXC и Bybit, предварительно фильтровал монеты по объёму и ликвидности, а затем передавал отобранные данные в AI-анализ по заданной стратегии. Результатом становились сигналы в Telegram.

МОЯ РОЛЬ

Я придумал концепцию, определил стратегию, параметры и логику работы системы. ChatGPT помогал с технической реализацией, интеграциями и настройкой.

CR13 AI Analyst

Разработка аналитического ядра для автоматического поиска торговых ситуаций на рынке фьючерсов и подготовки сигналов.

ЗАДАЧА

Создать основу аналитического приложения, которое получает рыночные данные, отбирает подходящие инструменты и помогает находить торговые ситуации по заданным правилам.

РЕАЛИЗОВАНО

Подключение к публичному MEXC USDT-M Futures API, фильтрация контрактов по ликвидности и спреду, обработка свечных данных, расчёт ATR, анализ локальных экстремумов и сохранение кандидатов в SQLite.

МОЯ РОЛЬ

Определяю назначение и архитектуру проекта, формулирую задачи для компонентов, использую ChatGPT для генерации и доработки кода, самостоятельно запускаю систему, проверяю результаты, анализирую ошибки и уточняю требования.

ТЕХНОЛОГИИ

Python · MEXC Futures Public API · SQLite · Pandas · NumPy · Requests · Pytest

Проект находится в разработке. Это аналитический инструмент, а не готовая торговая система; приватные торговые API не используются.
